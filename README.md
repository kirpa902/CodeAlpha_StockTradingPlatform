# Stock Trading Platform (Java)

## 📌 Description
A console-based Java application that simulates a stock trading environment. It allows users to view market data, buy/sell stocks, and track portfolio performance.

## 💡 Features
- View stock market data
- Buy and sell stocks
- Track user portfolio
- Calculate total portfolio value
- Transaction tracking using OOP

## 🛠️ Technologies Used
- Java
- Object-Oriented Programming (OOP)
- HashMap & ArrayList

## ▶️ How to Run
Compile:
javac StockTradingPlatform.java

Run:
java StockTradingPlatform
